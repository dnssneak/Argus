Audit Pipeline

Surface Mapping Workflow

Argus coordinates multi-layered target profiling, passive subdomain harvesting, port service verification, and PDF auditing.

01

Define Audit Scope

Register target domains or subnet ranges. Argus structures scope records into clean, organized projects to track vulnerabilities over time.

02

Passive Subdomain Mapping

Harvest active hostnames passively using Certificate Transparency (CT) log records and public WHOIS lookups without initiating connections.

03

Active Service Port Detection

Perform deep scans to discover open network ports and query active service banners to identify precise software versions and OS releases.

04

Web Stack Fingerprinting

Scan application layers to map HTTP server software, CDNs, content management frameworks, programming modules, and missing security flags.

05

Download Audit Reports

Compile assessment results and export structured, compliance-ready reports in PDF, HTML, or raw text for remediation.
