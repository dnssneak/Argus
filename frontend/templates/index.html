Reconnaissance Workflow

Argus coordinates multi-layered target profiling, passive subdomain harvesting, port service verification, and PDF auditing.

01

Define Audit Scope

Register target domains or subnet ranges. Argus structures scope records into clean, organized projects to track vulnerabilities over time.

02

Passive Subdomain Mapping

Harvest active hostnames passively using Certificate Transparency (CT) log records and public WHOIS lookups without initiating connections.

03

Active Service Port Detection

Perform deep scans to discover open network ports and query active service banners to identify precise software versions and OS releases.

04

Web Stack Fingerprinting

Scan application layers to map HTTP server software, CDNs, content management frameworks, programming modules, and missing security flags.

05

Download Audit Reports

Compile assessment results and export structured, compliance-ready reports in PDF, HTML, or raw text for remediation.

Technical Specifications & FAQ Knowledgebase

Everything you need to know about the Argus audit engine, scanning protocols, and API integration.

Argus queries public Certificate Transparency (CT) logs and DNS record archives (A, AAAA, MX, TXT). Because data is harvested from third-party certificate providers and cached name servers, target infrastructure is never directly touched, preserving complete operational stealth.

Yes. Active port scanning uses optimized TCP SYN and connect probes with configurable packet rates (default 1000 p/s). You can adjust scan intensity from stealthy single-thread queries to rapid parallel scans directly inside the dashboard control panel.

Yes. Argus exposes REST endpoints (/api/v1/projects, /api/v1/assets, /api/v1/scans) returning structured JSON payload responses ready for automated ingestion into Splunk, Elastic SIEM, Datadog, or custom SOC pipelines.

The fingerprinting engine inspects HTTP response headers, server banners (Nginx, Apache, IIS), TLS cipher suites, ALPN protocols, CMS frameworks (WordPress, Drupal), programming stacks, CDN providers, and missing security headers (HSTS, CSP, X-Frame-Options).

When an audit scope completes, Argus compiles asset inventories, port status matrices, vulnerability advisories, and host profiles into compliance-ready PDF and HTML executive summaries ready for immediate client download.

Argus groups targets under isolated Project Scopes. Each project maintains its own dedicated asset inventory, historical scan delta comparisons, WHOIS snapshots, and vulnerability severity tracking over time.
